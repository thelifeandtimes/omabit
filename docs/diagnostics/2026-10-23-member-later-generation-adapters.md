# Later-generation lifecycle adapters

Private adapters can observe a replacement's retained Stop, retire its exact cleanly
exited container, resume the same pier at the next generation, and collect separate
readiness. Resume accepts exactly one original or replacement Stop source. Earlier
receipts remain intact and uncertain effects cannot be replayed as new success.

Sixteen inert-engine cases exercise generations2→3 and3→4 with running/stopped
peers, lost Stop/removal/Start replies, conflicting sources, missing history and
changed namespace. Saved state objects/bytes are unchanged. The full adapter race
suite passes in101.584s. The additive ordered-history prefix helper passes the
full model race suite in2.982s and final vet passes. It validates the entire history
before returning independent ordered prefix receipts. The full adapter suite
compiled before that additive helper; model tests and final vet cover it separately.

This is source qualification. Schema34 still permits one resume per member, and
actual VM21 was frozen before these changes. Later persistence, changed-peer
readiness and coordinated anchor recovery remain to be integrated.
