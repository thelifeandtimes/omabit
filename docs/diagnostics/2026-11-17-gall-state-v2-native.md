# Gall v2 native application loop

The single-peer native loop passes for the exact
[eight-file sample and inputs](../../internal/appdev/samples/gall-state-v2/native-qualification.json).
The5528-byte payload has a JSON text poke mark, JSON/MIME response conversions,
bill and only its required agent libraries. The frozen v1 definition remains
unchanged; its noun API has no browser-JSON decoder. Its earlier pending status is
not upgraded by testing a different source version.

The gate composes actual managed API/SQLite, collector/Unix transport and bounded
staging with a fresh owned kernel. Default creation policy blocks before dispatch;
fixture-authored scoped grants permit creation/commit while publication stays
blocked. The final gate activates cold before its separate read-only native
agent, bill and custom mark compilation probes. The exact active agent, JSON scry, Gall poke acknowledgement and watch
facts are checked separately. Duplicate and object payload nacks preserve state.

A changed-source commit emits a new on-load marker and preserves revision1 state.
The supervisor records the exact owned PID/start/executable/pier identity before
one SIGTERM, waits for clean exit, and resumes the same pier without creation
flags. The existing owner session reads the persisted value; a fresh subscription
reconciles it, and a second acknowledged write produces exact revision2 state.
Own channels and session clean up, and the final runtime exits cleanly. No Unix
mount request occurs and the autocommit timer remains inactive.

All seven capsules shut down cleanly. The first two HTTP500 outcomes are not proof
that no effect occurred; later success does not rewrite those interruptions or
establish their root cause. The third and fifth failures have direct compiler/
conversion evidence. The fourth failure is a diagnostic error, not an app failure.

Private raw logs, original receipts and exact capsule bindings remain in private
evidence. The public report carries their hashes and explicit scope. The run used
private user/PID/mount/network namespaces, loopback only,4GiB RAM/no swap/one CPU,
128 tasks and2GiB declared scratch. Aggregate measured allocation stayed below
the temporary48GiB cap; shared compiler/module caches were conservatively charged.
Only classified redundant task copies may be retired with manifests/tombstones.

Managed lifecycle/container/transport, installed upgrade, production deployment,
multi-peer app behavior, abrupt power loss, state migration, named product clients
and Grubbery remain outside this gate. No production or manual-review state was
changed. Gall-06 used compiler warmup; the final report binds gall-07's separate
cold-activation pass rather than inferring it from the earlier run.
