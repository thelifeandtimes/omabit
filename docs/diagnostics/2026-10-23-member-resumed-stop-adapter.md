# Replacement Stop adapter

The private driver reconstructs current contracts from causal history, including
generation2/3 replacements and historical exits for peers that retain their exact
current container. It uses the existing fresh inspection, committed dispatch and
single TERM path. Initialized replacement pier identity is checked at each bracket.

Twenty-four execution cases and nine refusal cases pass against inert engine
responses and disposable filesystem fixtures. They cover stopped peers, live locks,
lost acknowledgement, failed commit, changed processes/namespaces/piers, unknown
containers, caller aliasing and invalid history. State objects/bytes are retained.
The full runtimequalify race suite passes in92.603s; vet is clean. Original logs and
source hashes are retained in the companion report. This does not qualify actual
Docker Stop, durable current-generation scheduling or changed-anchor recovery.
