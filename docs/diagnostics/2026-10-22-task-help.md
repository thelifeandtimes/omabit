# Offline task-oriented CLI guidance

`urbit-collector help` now lists five short task topics: runners, managed ships,
imports, Eyre/plugin connections and hosting. `help TOPIC` describes relevant
commands, their effects and the next checks; `COMMAND --help` remains the source
of actual flags. JSON is the default, with a versioned guidance document;
`--format text help` provides readable navigation. Existing full `--help` remains.

Guidance is available before selecting or contacting a runner, even when selection
is broken. It explicitly distinguishes local guidance from the live `hello`
capability/authority response. It covers asynchronous receipts, unreachable versus
stopped state, stale revisions, uncertain dispatch, stopped import completion,
broad independent Eyre sessions and direct plugin data transport. It neither
executes suggested commands nor infers authorization. The operator skill links
agents into this path and retains a fallback for older binaries.

Validation: all twelve built-CLI overview/topic paths passed in JSON and text
inside a private namespace with no host HOME, network or runner socket. Parser
tests follow each advertised command into its real help handler, reject malformed
help requests and verify no registry is created. The collector race suite, vet,
skill validation and diff whitespace checks passed. See
[the evidence record](2026-10-22-task-help.json).

This adds navigation; it does not complete the agent-usability gate. Realistic
task walkthroughs, structured next actions for runtime errors, developer skills
and packaging/distribution remain. The completed import VM used its previously
frozen collector, not this later help change.
