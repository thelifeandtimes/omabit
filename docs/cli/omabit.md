## copy-code

```text
Usage: omabit [--config-dir DIR] copy-code --runner NAME --expected-runner-id ID --instance INSTANCE --revision N --container-id FULL_ID
Retrieve the exact running ship's +code and hand it to a private Wayland clipboard
provider for at most 30 seconds. Requires wl-copy. Does not print or save the code;
exiting releases only this process's own clipboard selection.
```

## remote-setup

```text
Usage of remote-setup:
  -host string
        existing SSH alias or hostname
  -id string
        resume an existing remote setup ID
  -name string
        connection name; defaults to the host
  -owner string
        existing non-root pier owner for fresh hosts
  -port uint
        optional existing SSH port
  -revoke
        revoke this pairing after remote administrator authorization
  -role string
        operator or observer (default "operator")
  -ssh-config string
        optional absolute OpenSSH config file
  -user string
        optional SSH login account
```

## setup

```text
Usage: omabit [--format text] setup | setup-status

Set up this computer's official-runtime host, services and private desktop access.
Run as your desktop user; only the host step asks for OS authorization. Existing
piers, runner/SSH identities and other access grants are preserved. Prerequisites
are checked first. setup-status does not install or generate keys.
```

## theme-auto

```text
Usage: omabit [--config-dir DIR] [--state-dir DIR] theme-auto NAME --expected-ship-id ID --enabled=true|false
Set the selected enrollment's automatic-publishing preference. The enrollment ID
must match; this preference change does not itself publish a palette.
```

## theme-migrate

```text
Usage: omabit [--config-dir DIR] [--state-dir DIR] theme-migrate [--legacy-dir DIR] [--apply --expected-digest DIGEST]
Default: preview the legacy Theme state and its digest. Apply pauses the legacy
publisher and transfers its sessions/preferences without logout. Review the
preview before applying; do not repeat an uncertain migration blindly.
```

## theme-preview

```text
Usage: omabit theme-preview
Read the current local appearance as a palette; no ship or preference writes.
```

## theme-publish

```text
Usage: omabit [--config-dir DIR] [--state-dir DIR] theme-publish NAME --expected-ship-id ID
Publish the local palette once to the exact enrolled ship. Network write.
```

## theme-status

```text
Usage: omabit [--state-dir DIR] theme-status
Read saved automatic-publishing preferences; no ship traffic.
```

## theme-sync

```text
Usage: omabit [--config-dir DIR] [--state-dir DIR] theme-sync
Publish the current local palette to independently enrolled ships with automatic
publishing enabled. Reports partial failure; does not retry failed writes.
```
