# Tlon Messenger for Omarchy

Status: product and protocol specification required before implementation.

This workstream will build an Omarchy-native client for Tlon Messenger using the
user's Urbit identity and compatible on-ship data. It should feel integrated
with the Omarchy shell while remaining interoperable with the supported Tlon
protocol surface.

The first specification should answer:

- Which Tlon/Groups APIs and data models define the compatibility target?
- Does the first release focus on direct messages, groups, or both?
- Which process owns Eyre sessions, subscriptions, offline cache, and retries?
- How do desktop notifications, unread state, attachments, and deep links work?
- Which identity/profile information is shared with the Pals workstream?

No runtime or protocol implementation is committed by this placeholder.
