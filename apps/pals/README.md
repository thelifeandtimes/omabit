# Pals Discovery

Status: product and protocol specification required before implementation.

This workstream will integrate `%pals` into Omabit so Omarchy users can discover
other participating Urbit users with explicit visibility and consent controls.
It is a shared discovery capability for the desktop, not a hidden dependency of
Tend or Tlon Messenger.

The first specification should answer:

- Which existing `%pals` APIs and data are stable enough to consume?
- What information is public, mutual, local-only, cached, or revocable?
- How are spam, impersonation, blocking, and stale profiles handled?
- Which UI belongs in a shared service versus an application-specific picker?
- What versioned contract exposes identities to other Omabit applications?

No runtime or protocol implementation is committed by this placeholder.
