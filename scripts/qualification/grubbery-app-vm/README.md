This prepared qualification uses the actual installed runner and its rootless
Docker/curl source transport. It does not inject a backend. One fresh ordinary
fake receives the pinned framework and the exact maintained source versions.
Real CLI and stdio MCP calls exercise selected review/begin/exact phases, saved
receipt parity, state preservation/new code, supported Stop/Start with a new
container, manager restart and immutable completed-phase replay. State probes
are fixed test-only owner requests through an exact enabled private local route;
no public state API or complete workflow readiness is implied.

Run only with a clean source commit and matching three executables/test helper.
The helper uses the existing link-time `managed.issuesVMSourceRevision` pin and
refuses outside the explicit QEMU/scenario/user guard. The host script verifies
the pristine input inventory, complete pinned framework, frozen runtime/pill and
source identities. `--run` submits an independent temporary supervisor; no work
occurs by default. Supply every explicit input from `--help`; existing output
folders never resume. This is not an installed-host or manual-review procedure.

one-VM scope is10GiB/no-swap/one-CPU with an8GiB guest, no NIC and no host HOME,
run, runner/Docker socket or keyring mounts. Admission requires12GiB available
memory and reserves2GiB additional storage under the explicitly selected40/48GiB

service has a2400-second bound; the helper has a30-minute context/35-minute test
bound. Only the newly created scope is terminated on interruption. Failed phases,
original receipts, logs and images remain for supported observation/retention.

Four source tests cover no-effect default invocation, output refusal before
input/process access, exact guest guards and wrong workflow/schema refusal.
The helper compiles/skips outside the explicit guest. These are preparation gates;
a live product result is required before claiming Docker transport qualification.

A narrow harness/documentation follow-up may select `--artifact-source` with the
exact frozen ancestor. Any changed Go/module/embedded input refuses, and receipts
